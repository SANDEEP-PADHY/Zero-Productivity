# UI Specification

## Visual system
Modern minimalist neo-brutalism, strong typography, generous whitespace, clear hierarchy, restrained accent usage, responsive bento/grid layouts where useful.

Palette:
- Black `#080808`
- Gunmetal `#3D3D3D`
- White `#FFFFFF`
- Papaya Whip `#FFECD1`
- Stormy Teal `#15616D`

## Surfaces
Overview, Timeline, Apps, Websites, Insights, Devices, Rules, Settings, Account/Auth, desktop status UI.

## Timeline
Show activity, exact start/end, duration, classification, device, and optional idle/media indicators.

## Design authority
Stitch owns approved visual design. Antigravity implements it.
