# Stitch Context

Stitch is the UI design authority. Designs should communicate precise time tracking, timelines, analytics, device state, privacy, and configurable rules.

Visual language: minimalist neo-brutalism, strong typography, whitespace, clear hierarchy, restrained palette, bento/grid layouts where useful.

Palette: `#080808`, `#3D3D3D`, `#FFFFFF`, `#FFECD1`, `#15616D`.

Required surfaces: Overview, Timeline, Apps, Websites, Insights, Devices, Rules, Settings, Account/Auth, desktop status.

Do not let decoration compete with analytics.
