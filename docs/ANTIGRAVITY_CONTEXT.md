# Antigravity Context

You are implementing this repository. Read `README.md` and the relevant files in `/docs` before changing code.

## Hard rules
- Do not invent requirements.
- Do not redesign architecture without an ADR.
- Do not hard-code productivity judgments.
- Do not replace SQLite with JSON.
- Do not expose PostgreSQL publicly.
- Do not commit secrets.
- Do not build unrelated features.
- Prefer small, testable changes.
- Update documentation when behavior changes.

If starting from an empty repository, implement the Windows collector and shared session model first.
