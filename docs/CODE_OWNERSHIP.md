# Code Ownership

- `apps/desktop` — desktop client/collector
- `apps/browser-extension` — browser integration
- `apps/android` — Android client
- `apps/dashboard` — web dashboard
- `packages/core` — shared tracking concepts
- `packages/shared-types` — contracts
- `packages/database` — persistence abstractions
- `packages/sync` — sync protocol/client
- `packages/rules` — rules engine
- `supabase` — backend schema/functions
- `docs` — product/architecture source of truth
